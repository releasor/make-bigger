# 虚拟盘 MVP 使用说明

## 当前版本能做什么

这个 MVP 可以在本地运行一条 A 股样例数据上的虚拟交易闭环。它支持一个结构化规则策略、可切换的策略工作台、虚拟订单和成交、组合监控、当前执行阶段、最近审计事件、短线信号中心、手动标记买入后的卖出监控，以及每日指标报告。

## 本地命令

安装依赖：

```powershell
npm.cmd install
```

运行测试：

```powershell
npm.cmd run test
```

运行类型检查：

```powershell
npm.cmd run typecheck
```

启动 API 和 Web 控制台：

```powershell
npm.cmd run dev
```

打开 Web 控制台：

```text
http://127.0.0.1:5173
```

运行 PowerShell API 冒烟测试：

```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8787/api/simulation/run' -ContentType 'application/json' -Body '{}'
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/monitoring'
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/report/daily'
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/short-term/signals'
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/manual-positions'
```

## 安全边界

当前版本只做虚拟交易和研究提示。它不会连接券商，不会发出真实订单，也不会管理真实资金。

短线信号中心只展示样例行情上达到高置信度阈值的“特别值得关注”虚拟买入提示。它不是投资建议，也不会自动替用户确认真实买入。用户点击“标记已买入”后，系统只会把这笔样例持仓加入虚拟监控，并持续检查止损价、RSI 转弱和跌破 MA20 等卖出提醒。

## 第一条可用流程

1. 打开 Web 控制台。
2. 在结构化规则、画布模块、AI 助手之间切换。
3. 根据当前市场状态点击顶部按钮。
4. 查看实时监控状态、当前执行阶段和最新操作。
5. 查看日报指标。
6. 查看最近审计事件明细。
7. 休盘时间查看盘后分析。
8. 在“短线信号中心”查看 AI 虚拟交易提示、购买依据、建议仓位和风险边界。
9. 对认可的信号点击“标记已买入”，进入人工持仓监控。
10. 查看“人工持仓监控”中的卖出提醒；没有触发时显示继续监测。

## 短线信号中心

当前短线信号由样例分钟线计算，默认只展示置信度不低于 85 分的买入提示。评分口径包括：

- 收盘价突破 MA20。
- 成交量达到 20 日均量的 1.5 倍以上。
- 日内涨幅达到 1.5% 以上。
- RSI14 处在 35-65 的非过热区间。
- 价格接近当前周期高位。

每条信号会展示：

- 标的、时间、现价和置信度。
- “特别值得关注”推荐标签。
- 建议仓位，当前默认 10%。
- 止损观察价，当前默认按 8% 止损幅度计算。
- 购买依据和风险边界。

手动标记买入后，系统会记录 `manual_buy_marked` 审计事件，并在 `/api/manual-positions` 中返回当前人工持仓和卖出提醒。

## 顶部按钮语义

顶部按钮会随市场状态改变，避免把休盘回放误解成实时交易：

- 交易时间：显示“运行虚拟盘”，表示按当前策略执行一次虚拟交易流程。
- 盘后休市：显示“生成盘后复盘”，表示使用样例/历史数据生成复盘和次日观察项，不触发实时交易。
- 其他休盘时段：显示“运行历史回放”，表示做离线回放，不代表当前市场正在交易。

## 市场状态

Web 控制台会按北京时间判断 A 股常规交易时段：

- 09:15-09:25：开盘集合竞价。
- 09:30-11:30：连续竞价。
- 11:30-13:00：午间休市。
- 13:00-14:57：连续竞价。
- 14:57-15:00：收盘集合竞价。
- 15:00 后：盘后休市，并显示盘后分析。

当前版本按工作日和常规时段判断市场状态；交易所节假日休市日历后续需要接入正式交易日历。

## 指标口径

交易胜率：盈利平仓交易数 / 已平仓交易数。

信号命中率：命中信号数 / 已评估信号数。

策略达标：当配置的收益目标和回撤目标同时满足时为“达标”。
