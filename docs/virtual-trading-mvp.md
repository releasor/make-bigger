# 虚拟盘 MVP 使用说明

## 当前版本能做什么

这个 MVP 可以在本地运行一条 A 股真实行情驱动的虚拟交易闭环。它支持一个结构化规则策略、可切换的策略工作台、公开行情数据适配器、虚拟订单和成交、组合监控、当前执行阶段、最近审计事件、短线情报中枢、短线信号中心、手动标记买入后的卖出监控，以及每日指标报告。

## 本地命令

安装依赖：

```powershell
npm.cmd install
```

运行测试：

```powershell
npm.cmd run test
```

运行类型检查：

```powershell
npm.cmd run typecheck
```

启动 API 和 Web 控制台：

```powershell
npm.cmd run dev
```

打开 Web 控制台：

```text
http://127.0.0.1:5173
```

运行 PowerShell API 冒烟测试：

```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8787/api/simulation/run' -ContentType 'application/json' -Body '{}'
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/monitoring'
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/report/daily'
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/market-data/status'
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/intelligence/short-term'
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/short-term/signals'
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/manual-positions'
```

## 安全边界

当前版本只做虚拟交易和研究提示。它不会连接券商，不会发出真实订单，也不会管理真实资金。

短线信号中心只展示真实行情或真实缓存上达到高置信度阈值的“特别值得关注”虚拟买入提示。它不是投资建议，也不会自动替用户确认真实买入。用户点击“标记已买入”后，系统只会把这笔虚拟持仓加入监控，并持续检查止损价、RSI 转弱和跌破 MA20 等卖出提醒。

## 真实数据接入

当前无 token 版本默认优先使用东方财富公开行情接口拉取 A 股日线和分钟线；如果该接口临时断连，会先尝试腾讯公开 K 线接口作为备援，再尝试腾讯公开实时行情接口。系统会基于可用行情计算策略所需指标：

- `ma20`：20 周期均价，样本不足时使用当前可用窗口。
- `avgVolume20`：20 周期平均成交量，样本不足时使用当前可用窗口。
- `rsi14`：14 周期 RSI，样本不足时使用当前可用窗口或中性值。

接口成功后，系统会把最近一次真实行情快照缓存到：

```text
tmp/market-data-cache/eastmoney-snapshot.json
```

数据源状态会在 Web 控制台显示：

- “真实数据”：本次请求成功拿到公开行情。
- “真实缓存”：公开行情源临时不可用，使用最近一次真实行情缓存。
- “样例数据”：公开行情源不可用，且本地没有真实缓存；这时页面会显示告警。

当页面显示 `tencent-kline` 时，表示东方财富 K 线源不可用，但腾讯公开 K 线源仍可用。该备援会提供真实日线深度，分钟级数据使用实时盘口快照补齐。当页面显示 `tencent-quote` 时，表示 K 线源均不可用，但腾讯实时行情源仍可用；该档只适合保持虚拟盘和监控继续运行，历史回放质量仍以东方财富、腾讯 K 线或正式授权数据源为准。

当前默认股票池为 `000001.SZ` 和 `600000.SH`。公开行情源存在限流、接口变更和授权边界风险；生产或重资金使用前，应切换到正式授权的数据源，例如 Tushare Pro、券商行情、交易所授权行情或用户自有数据。

## 第一条可用流程

1. 打开 Web 控制台。
2. 在结构化规则、画布模块、AI 助手之间切换。
3. 根据当前市场状态点击顶部按钮。
4. 查看实时监控状态、当前执行阶段和最新操作。
5. 查看日报指标。
6. 查看最近审计事件明细。
7. 休盘时间查看盘后分析。
8. 在“行情数据”状态块确认当前使用真实数据、真实缓存或样例数据。
9. 在“短线情报中枢”查看短期展望、操作建议、板块轮动、重点跟踪对象、风险信号和外部情报状态。
10. 在“短线信号中心”查看 AI 虚拟交易提示、购买依据、建议仓位和风险边界。
11. 对认可的信号点击“标记已买入”，进入人工持仓监控。
12. 查看“人工持仓监控”中的卖出提醒；没有触发时显示继续监测。

## 短线情报中枢

短线情报中枢是新增的研究层，不直接下单。它会基于当前真实行情或真实缓存生成中文报告，输出：

- 短期展望：根据观察池的涨跌、均线位置、放量情况和强势数量判断情绪偏强、中性或偏弱。
- 操作建议：显示“进攻观察”“精选跟踪”或“防守观望”，并明确这是虚拟盘研究态度。
- 板块轮动：按股票到板块的映射聚合强度、持续性和样本质量。
- 重点跟踪对象：展示趋势突破、放量、接近异动或接近涨停的候选股，并给出理由和风险备注。
- 风险信号：识别 RSI 过热、跌破 MA20、情绪偏弱等风险。
- 核心结论：总结当前优先跟踪对象和风险数量。

当前版本已经真实计算 K 线、趋势、市场情绪、板块轮动、强势股、异动和接近异动股票。龙虎榜、新闻催化、主线题材和公告已经接入公共来源状态；其中主线题材在 EastMoney 题材源不可用时，会使用腾讯实时报价和本地板块映射生成 `tencent-sector-rotation` 备援状态，不会显示为不可用，也不会编造席位或新闻。

`/api/intelligence/short-term` 会返回完整报告。后续接入交易所公开信息、公告、新闻或用户自有数据服务时，应通过同一份外部情报状态替换 provider。

## 短线信号中心

当前短线信号由真实分钟线或真实缓存计算，默认只展示置信度不低于 85 分的买入提示。评分口径包括：

- 收盘价突破 MA20。
- 成交量达到 20 日均量的 1.5 倍以上。
- 日内涨幅达到 1.5% 以上。
- RSI14 处在 35-65 的非过热区间。
- 价格接近当前周期高位。

为了避免真实分钟线下一只股票连续多分钟重复刷屏，系统会对同一标的只保留最新一条高置信度买入提示。

每条信号会展示：

- 标的、时间、现价和置信度。
- “特别值得关注”推荐标签。
- 建议仓位，当前默认 10%。
- 止损观察价，当前默认按 8% 止损幅度计算。
- 购买依据和风险边界。

手动标记买入后，系统会记录 `manual_buy_marked` 审计事件，并在 `/api/manual-positions` 中返回当前人工持仓和卖出提醒。

## 顶部按钮语义

顶部按钮会随市场状态改变，避免把休盘回放误解成实时交易：

- 交易时间：显示“运行虚拟盘”，表示启用自动虚拟交易；后端按轮询间隔持续运行虚拟盘，直到盘后休盘自动停用。
- 盘后休市：显示“生成盘后复盘”，表示使用真实行情或真实缓存生成复盘和次日观察项，不触发实时交易。
- 其他休盘时段：显示“运行历史回放”，表示做离线回放，不代表当前市场正在交易。

自动虚拟交易使用 API 进程内的同一个虚拟组合。每次轮询会从上一轮现金、持仓和权益继续，并跳过已经处理过的旧信号，避免同一批行情在下一轮重复触发交易。当前组合和已处理信号只保存在内存中；重启 API 进程后会回到初始虚拟资金。

## 市场状态

Web 控制台会按北京时间判断 A 股常规交易时段：

- 09:15-09:25：开盘集合竞价。
- 09:30-11:30：连续竞价。
- 11:30-13:00：午间休市。
- 13:00-14:57：连续竞价。
- 14:57-15:00：收盘集合竞价。
- 15:00 后：盘后休市，并显示盘后分析。

当前版本按工作日和常规时段判断市场状态；交易所节假日休市日历后续需要接入正式交易日历。

## 指标口径

交易胜率：盈利平仓交易数 / 已平仓交易数。

信号命中率：命中信号数 / 已评估信号数。

策略达标：当配置的收益目标和回撤目标同时满足时为“达标”。
