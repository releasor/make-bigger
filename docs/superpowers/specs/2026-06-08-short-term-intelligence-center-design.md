# 短线情报与决策中枢设计

## 背景

用户希望平台不仅依赖日线信号，还能结合历史 K 线、分时走势、趋势、市场情绪、板块轮动、主线题材、强势股、龙虎榜、新闻催化、风险信号、异动股票和接近异动股票，形成短期展望、操作建议、重点跟踪对象、核心结论和操作理由。

当前系统已经具备真实行情接入、虚拟盘运行、短线买入信号、手动买入标记和卖出监控。本次新增“短线情报与决策中枢”，作为独立研究层，为信号和虚拟盘提供市场上下文，不直接连接券商，也不承诺盈利。

## 目标

1. 生成中文短线情报报告，覆盖趋势、情绪、板块、强势股、异动、风险、龙虎榜和新闻催化。
2. 对每个结论附带可读的操作理由和数据来源状态。
3. 当真实外部数据不足时明确提示“数据不足/待接入/来源不可用”，不伪造新闻、龙虎榜或题材事实。
4. 在 API 和前端实时监控中展示报告，支持虚拟盘运行后刷新。
5. 保持当前平台为虚拟盘和研究工具，不发出实盘订单。

## 非目标

1. 不实现券商实盘交易接口。
2. 不保证或暗示自动赚钱。
3. 不在缺少来源的情况下编造最新新闻、龙虎榜席位或题材归因。
4. 不把外部公开数据当成交易所授权行情。

## 架构

新增 `shortTermIntelligence` 引擎模块。它接收当前真实行情快照、策略股票池和可选外部情报源，输出 `ShortTermIntelligenceReport`。

报告由五个层次组成：

1. 市场趋势与情绪：基于历史 K 线和最新分时，计算均线位置、涨跌家数、强势数量、量能变化和风险温度。
2. 板块轮动：根据股票到板块的映射聚合强度、持续性和样本质量，输出领先板块与退潮板块。
3. 强势股与异动：识别趋势突破、放量、接近涨停、接近日内异动和风险过热。
4. 催化与龙虎榜：提供数据槽位，优先接入真实公开来源；未配置时显示“待接入”并说明不会影响已计算的 K 线结论。
5. 操作建议：输出短期展望、仓位态度、重点跟踪对象、风控边界和核心结论。

## 数据来源策略

行情数据继续使用现有 EastMoney K 线数据提供器和真实缓存机制。新增外部情报源采用统一状态：

- `available`：本次报告使用了真实来源。
- `empty`：真实来源可用，但本次无有效事件。
- `unavailable`：来源请求失败或格式无法解析。
- `not_configured`：该来源尚未配置，界面必须明确展示。

第一版会把行情、板块和异动计算做成可运行闭环；龙虎榜、新闻和题材先进入真实数据边界与报告槽位，不编造内容。后续接入官方交易公开信息、交易所公告、可验证新闻 API 或本地数据服务时，只需要替换 provider。

## 领域模型

新增核心类型：

- `MarketSentimentSnapshot`：市场情绪温度、涨跌家数、强势数量、量能倍数、趋势标签。
- `SectorRotationItem`：板块名称、股票数量、强度分、持续性分、样本质量和代表股票。
- `StrongStockCandidate`：股票、现价、趋势分、量能分、异动分、标签、买入依据和风险备注。
- `ExternalIntelItem`：龙虎榜、新闻、题材或公告事件，包含标题、来源、可信度、时间和关联股票。
- `RiskSignal`：风险等级、触发原因、关联股票和处理建议。
- `ShortTermIntelligenceReport`：短期展望、操作建议、重点跟踪、核心结论、数据来源状态和上述明细。

## 计算规则

市场情绪：

- 个股最新价高于 MA20 记为趋势向上。
- 最新收盘高于前一日收盘记为上涨。
- 成交量高于 20 周期均量记为量能活跃。
- 情绪分由上涨占比、趋势占比、强势股占比和量能倍数组合得到，范围 0-100。

板块轮动：

- 按板块聚合个股趋势分、涨跌幅、量能倍数和样本数量。
- 样本少于 2 只时仍展示，但标记“样本不足”。
- 领先板块进入重点观察，退潮板块进入风险提示。

强势股与异动：

- 趋势突破：最新价高于 MA20 且近 5 个交易日涨幅为正。
- 放量：最新量能高于 20 周期均量 1.5 倍。
- 接近涨停/异动：最新涨幅接近 A 股常见异动阈值，或分时涨幅、量能、接近最高价同时增强。
- 过热风险：RSI 高于 75、短期涨幅过快或放量冲高回落。

操作建议：

- 情绪分高且强势股充足：`进攻观察`，仅允许小仓位虚拟跟踪。
- 情绪中性：`精选跟踪`，等待确认信号。
- 情绪弱或风险信号密集：`防守观望`，不追高。

所有建议文案必须带“虚拟研究/观察”语义，不直接写成实盘指令。

## API

新增接口：

- `GET /api/intelligence/short-term`

返回：

- `report`：完整短线情报报告。
- `source`：行情和外部情报来源状态。

服务端在刷新行情、短线信号、手动买入和虚拟盘运行后都可以复用同一份报告生成逻辑。

## 前端

新增“短线情报中枢”面板，展示：

1. 短期展望、操作建议和核心结论。
2. 市场情绪温度与趋势标签。
3. 板块轮动排行。
4. 强势股/异动/接近异动股票。
5. 龙虎榜、新闻催化和主线题材的数据状态。
6. 风险信号与风控建议。

界面风格保持交易工作台的克制密度：信息清晰、可扫描，不做营销页。

## 测试

1. 引擎测试：报告能基于 K 线识别情绪、板块、强势股、风险和数据不足状态。
2. API 测试：接口返回报告，并包含真实行情来源状态。
3. 前端测试：页面加载后展示短线情报、操作建议、重点跟踪和外部数据状态。
4. 构建验证：`npm.cmd run test`、`npm.cmd run typecheck`、`npm.cmd run build`。
5. 浏览器验证：启动本地服务，截图检查面板可见且中文不溢出。

## 风险与边界

1. 公共行情源可能限频、变更或短时不可用，必须保留缓存和降级提示。
2. 板块映射在没有全市场数据库前只能覆盖当前观察池，报告必须显示样本质量。
3. 龙虎榜和新闻的实时性依赖后续数据源配置，第一版只展示真实状态槽位。
4. 平台输出的是虚拟盘研究建议，用户实盘操作需自行判断风险。
